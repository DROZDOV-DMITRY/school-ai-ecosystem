# Школьная интеллектуальная образовательная экосистема

Публичная исследовательская площадка проекта «Диссертация V1.0». Автор статьи и исследования — Дмитрий Дроздов.

## Страницы

- Главная страница — статья: `index.html`
- Отдельная страница — расширенная доказательная база: `research/index.html`

## Структура

```text
index.html              главная страница со статьёй
research/index.html     страница исследования
css/site.css            общие стили
images/school-ai-mark.svg фирменный знак и значок вкладки
downloads/              PDF, DOCX и реестр источников
content/                исходные версии Markdown
.nojekyll               отключает обработку Jekyll
```

Для публикации без отдельной сборки в настройках репозитория откройте **Settings → Pages** и задайте источник **Deploy from a branch**, ветку `main`, каталог `/(root)`. После сохранения GitHub Pages будет публиковать страницы и связанные папки из корня репозитория.
